# 04 - Logging and Final Honeypot

## Overview

In this final step, you'll bring everything together into a single honeypot script that listens on both HTTP and SSH ports. You'll also add structured logging to a file to record all interactions for later analysis.

This step marks the completion of your beginner-friendly honeypot setup.

## What the Final Script Does

The combined honeypot (`final-server.py`) does the following:

- Listens on two ports simultaneously:
  - Port 8080 for fake HTTP service
  - Port 2222 for fake SSH service
- Uses Python's `socket` and `threading` modules
- Responds to HTTP requests with a valid HTTP response
- Sends a fake SSH banner to incoming TCP connections
- Logs each interaction to a file (`honeypot.log`) in this format:

```
[2025-10-18 14:02:53] [HTTP] 192.168.1.11:53594 - GET /index.html HTTP/1.1
[2025-10-18 14:03:10] [SSH] 192.168.1.11:58212 - SSH-2.0-nmap
```

## File Structure

- `final-server.py` – the final honeypot script with logging and multithreading
- `honeypot.log` – log file auto-generated by the script (not committed to Git)
- Uses folders `03-ssh/` and `02-http/` logic merged in one

## Logging Format

Each line in the log includes:
- Timestamp
- Protocol type (HTTP or SSH)
- Source IP and port
- Data received (or error message)

This is useful for:
- Simulating SOC workflows
- Practicing log analysis
- Building detection rules later

## Run Instructions

1. Make sure Python 3 is installed
2. Run the script:

```
python3 final-server.py
```

3. Access the honeypot:
   - HTTP: `curl http://localhost:8080`
   - SSH: `nc localhost 2222`

4. Check the `honeypot.log` file for entries

## Notes

- This honeypot does not provide real service functionality
- It is meant to be used in a controlled lab or virtual machine
- Do not expose it to the public internet without firewall or containment
